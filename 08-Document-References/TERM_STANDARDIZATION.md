# Vietnamese-English terminology standard

| Canonical Vietnamese | Canonical English | Forbidden/ambiguous variants |
| :--- | :--- | :--- |
| yêu cầu | requirement | feature request when a normative obligation is meant |
| tiêu chí chấp nhận | acceptance criterion | done, good enough |
| bằng chứng | evidence | proof without a path or timestamp |
| chủ sở hữu chịu trách nhiệm cuối | accountable owner | approver when authority is not established |
| mô hình mối đe dọa | threat model | security diagram only |
| rủi ro tồn dư | residual risk | risk remaining, unless defined in the register |
| quyền | permission | role, unless role-to-permission mapping is explicit |
| triển khai | deployment | release, unless release decision is meant |

Use the canonical term in IDs, headings, tables, and cross-team prompts. Add a row here before introducing a recurring synonym.
